# 讲真，我给我审计团队写了套风险评估工具

之前我写过一些审计相关的东西，反响都还不错。但写完之后，一直有朋友在问，风险评估到底怎么打分才靠谱？每年排年度计划，先审谁，群里能吵一晚上。

确实，这事儿我太熟了。

年初排年度审计计划，全年就那点审计资源，先审谁？道理谁都认，按风险大小排。可风险大小怎么算？你指着登记册说"这条是高危"，领导问：凭什么？这个 4 分是拍脑袋拍的还是算出来的？

你翻出打分表，可能性 4、影响 4，一乘 16，落在"高"档。逻辑闭环。可下一个问题来了：影响为什么是 4？谁定的标准？换个审计员来打，是不是就变 3 了？

会议室安静了。

然后我就想，干脆自己写一套工具算了。

所以这次，我决定把这个工具从头到尾讲一遍。带很多跟我一样被"凭什么"问住的审计朋友，把风险评估这件事，做成能算、能查、能排计划的活儿。

坦率的讲，这套工具的设计逻辑，是我自己做过的工具里最让我满意的之一。而且它不要求你很硬核，Excel 就行，一个网页文件双击就能跑，真的。

如果你也在为排年度计划头疼，那相信我，这套打分逻辑，几乎能覆盖你日常风险评估里绝大部分需求。

我会用一个虚构的制造集团、三条典型风险，串起整篇。跟着看，你也能算。

OK，直接进正题。

## 一. 先造一个案例

先虚构一家企业：某装备制造集团，年营收 30 亿，采购、生产、销售、工程、资金、安全环保，一条龙。风险登记册上 24 条风险，覆盖 4 大类 12 个领域。

年初排年度计划，24 条不可能全审，先审谁，只能靠风险大小说话。

今天用主价值链上最典型的三条来演示：

**风险 A（采购）：供应商准入与围标串标。** 准入把关不严，关联供应商围标串标。近两年招标投诉 2 起，1 家关联供应商没申报。

**风险 B（生产）：生产安全事故隐患。** 高危作业管理不到位，年内出过 1 起未遂事故。

**风险 C（销售）：大客户依赖与应收账款回收。** 前五大客户占营收 55%，其中两家账期越拉越长，约 1.2 亿应收账款悬着。

## 二. 八维加权：影响从来不是一个数

传统做法是把"影响"打成 1 个分：大、中、小，或者 1-5。

但一条风险的真实影响，从来不是一个数说得清的。一次围标串标，采购价可能虚高（经济损失），可能被监管处罚（合规法律），供应商投诉发酵（声誉舆情），它本身就是舞弊（舞弊风险）。只打一个"影响分"，等于让每个审计员在脑子里偷偷做加权，而且每个人加的权重都不一样，排出来的序自然五花八门。

所以我干脆把"影响"拆成**八个维度**：

> **经济损失 / 合规法律 / 运营中断 / 声誉舆情 / 舞弊风险 / 战略影响 / 数据安全 / 健康安全**

每条风险按维度打 1-5 分，加权合成综合影响。

这里有几个关键设计，我一个个讲。

**第一个，维度独立性。** 各维度只评估自己的专属后果，经济损失不重复计入舞弊损失，声誉不重复计入合规处罚的舆情。不独立，加权就变成重复计分，分数虚高，排序失真。

**第二个，维度可留空。** 不适用就留空，留空维度不参与加权，权重在已打分维度上重新归一化。硬给不适用的维度打分，反而把排序带偏。

**第三个，分领域权重矩阵。** 这是我个人最得意的设计：不同领域的风险，八个维度的"含金量"不一样。资金活动，经济损失权重拉到 32%，钱的事主要看钱；信息系统，运营中断权重 28%，系统挂了比什么都严重；安全环保，健康安全 20%、合规法律 22%，人命和环保红线优先；采购与外包，舞弊权重 20%，采购是舞弊高发地，权重就给足。

12 个领域 × 8 个维度，每个领域一行权重矩阵。同一个"4 分"，落在资金活动里和落在信息系统里，贡献完全不同，排序才有区分度。

综合影响这么合成：

```
综合影响 I = MAX( Σ(wᵢ×维度ᵢ) / Σ(已评分维度的wᵢ) , 0.75 × 最高维度分 )
```

公式里 MAX 的第二项，是一票否决下限，一会儿单独讲。

## 三. 打分锚点：4 分到底是多少钱

八维拆完了，新的问题来了：**"经济损失 4 分"到底是多少钱？**

这个问题答不上来，排序就站不住。这是整个项目最花功夫的部分：给每一个维度的每一个分值，找到权威刻度。

拿"经济损失"举例，1-5 档直接锚定国资委《中央企业违规经营投资责任追究实施办法》的资产损失分级：

| 分值 | 锚点 | 依据 |
|---|---|---|
| 1 | < 100 万元，企业内部可消化 | 国资委办法（一般以下） |
| 2 | 100~500 万元，构成"一般资产损失" | 国资委办法 |
| 3 | 500~5000 万元，"较大资产损失" | 国资委办法；国务院令第 493 号 |
| 4 | 5000 万~1 亿元，"重大资产损失" | 国资委办法 |
| 5 | ≥ 1 亿元，危及企业生存 | 国务院令第 493 号 |

其他维度同理："合规法律"锚《个人信息保护法》第 66 条、《数据安全法》第 45 条的罚款区间，100 万以下一档、100~1000 万一档、1000 万~5000 万或营业额 5% 顶格一档，GDPR 的 2000 万欧元/全球营业额 4% 作国际对照；"舞弊风险"锚 ACFE《Occupational Fraud 2024》的损失基准，中位 14.5 万美元一档、75 分位 75 万一档、组织年均流失 5% 营收一档；"运营中断""健康安全"参照国务院令第 493 号的事故等级和 ISO 22301 的 RTO 分级；"战略影响"对齐 COSO ERM 2017 和《中央企业全面风险管理指引》。

全表 8 个维度 × 5 个分值，每个格子都有出处，直接内嵌在 Excel 工作簿里。

这意味着什么？打分从"个人经验"变成了"可复核的证据"。任何一档分数都能被追问"依据是什么"，登记册里每一行还有一个"打分依据"字段，逼着审计员写下引用的审计发现、监管动态或量化数据。

领导再问"凭什么这条排前面"，答案就是"按国资委办法，5000 万以上属重大损失，这条风险的敞口测算在 1.2 亿"。

这套锚点体系，是这个项目最值得抄走的部分。哪怕你不用我的工具，把这张锚点表拿去，你所在机构的评分标准立刻就有了骨架。

## 四. 两个容易忽略的设计

### 配角一：一票否决下限

假设一条风险八维打分是 2 / 1 / 2 / 2 / 1 / 1 / 4 / 1，经济影响轻微，唯独数据安全打了 4 分，大量个人信息泄露的那种。

按加权平均算，只有约 1.83 分，低风险。

但数据安全打到 4，按《个保法》第 66 条，就是 1000 万~5000 万罚款档，或者营业额 5% 顶格的量级。这么严重的法律后果，被其他六个"轻微"维度稀释成 1.83 分？这说不通。

如果允许稀释，这条风险会被排进年度计划的末尾，后果就是漏审。

所以规则是：综合影响不得低于最高维度分 × 0.75。上面的例子直接被抬到 3.0 分。**任何单一维度的致命后果，都不允许被其他维度的"还好"稀释掉。** 等会儿风险 C 会实战触发一次。

### 配角二：短板效应折减

固有风险算出来，只是风险的原貌。年度计划按剩余风险排：控制措施化解掉的部分，不该继续占用审计资源。

每条风险挂 1~N 条控制点，每条打 1-5 的有效性分，剩余风险按"最弱的关键控制"折减，木桶原理。

比如风险 A 挂了三道控制：电子招投标平台留痕（4 分）、供应商关联关系申报承诺（3 分）、评标专家随机抽取（4 分）。招投标平台是关键控制，它失效，其他两道都是摆设，所以折减只看这个 4 分：折减 55%。

还有一条更狠的规则：**没有控制点的风险，不做任何折减，剩余等于固有。** "没验证过的控制，不给信用。"你说你有控制，请先登记进来打个分；登记不上来，风险就按裸奔算，排序上一点便宜都占不到。

## 五. 三条风险走一遍

回到开头那家制造集团，把三条风险完整算一遍，看它们在年度计划里排成什么样。

### 风险 A（采购）：供应商准入与围标串标

| 步骤 | 计算 | 结果 |
|---|---|---|
| 可能性 L | 行业围标高发 + 近两年投诉 2 起 | 4 分 |
| 八维影响 | 经济4 / 合规4 / 运营3 / 声誉3 / **舞弊5** / 战略3 / 数据1 | 按采购与外包领域权重加权 ≈ 3.75 |
| 综合影响 | MAX(3.75, 0.75×5) | 3.75 |
| **固有风险** | 4 × 3.75 | **15.00 → 高** |
| 最弱关键控制 | 电子招投标平台留痕 | 4 分 → 折减 55% |
| **剩余风险** | 15.00 × 0.45 | **6.75 → 中** |

舞弊维度打了 5 分，采购是舞弊高发地，领域权重里舞弊占 20%，加权平均正好压着一票否决线。固有 15 分，高；关键控制（招投标全流程留痕）4 分，折减后 6.75，落到"中"，按工具给的频次建议是两年一轮。

招投标留痕这条关键控制保住了局面，但舞弊土壤还在，采购条线依然是每年的审计重点。

### 风险 B（生产）：生产安全事故隐患

| 步骤 | 计算 | 结果 |
|---|---|---|
| 可能性 L | 年内已发生 1 起未遂事故苗头 | 3 分 |
| 八维影响 | 经济4 / 合规5 / 运营5 / 声誉5 / 舞弊1 / 战略3 / 数据1 / **健康5** | 按安全环保领域权重加权 ≈ 4.70 |
| 综合影响 | MAX(4.70, 0.75×5) | 4.70 |
| **固有风险** | 3 × 4.70 | **14.10 → 高** |
| 最弱关键控制 | 高危作业许可制度 | 4 分 → 折减 55% |
| **剩余风险** | 14.10 × 0.45 | **6.35 → 中** |

安全环保领域的权重画像在起作用：健康安全 20%、合规法律与运营中断各 22%，生产事故的"综合影响"天然就高，加权平均 4.70 已经超过一票否决线。健康安全打 5 分，按 493 号令是"特别重大事故"（≥30 人死亡）的量级锚点，打分的人必须正视这个刻度。固有 14.10，高；高危作业许可 4 分，折减后 6.35，中，两年一轮。

安全防线目前是够用的，但一旦许可制度松动，直接回到高危。

### 风险 C（销售）：大客户依赖与应收账款回收

| 步骤 | 计算 | 结果 |
|---|---|---|
| 可能性 L | 两家大客户账期持续恶化 | 4 分 |
| 八维影响 | **经济5** / 合规2 / 运营3 / 声誉3 / 舞弊2 / 战略4 / 数据1 | 按资金活动领域权重加权 ≈ 3.35 |
| 综合影响 | MAX(3.35, **0.75×5**) | **3.75** |
| **固有风险** | 4 × 3.75 | **15.00 → 高** |
| 最弱关键控制 | 信用额度审批 | 3 分 → 折减 40% |
| **剩余风险** | 15.00 × 0.60 | **9.00 → 中** |

风险 C 是一票否决的实战现场：加权平均只有 3.35，但因为经济损失打了 5 分，1.2 亿应收敞口按国资委办法已是"重大资产损失"量级，综合影响被强制抬到 3.75。而信用额度审批这道关键控制只有 3 分，折减 40%，剩余 9.00，中风险，离"高"档线 12 只差 3 分。

两家大客户已经亮黄灯，信用审批得从 3 分往 4 分修。

## 六. 工具是三件套

最后说说工具本身。模型再漂亮，落不了地就是 PPT。

这个项目是"三件套"：**Excel 工作簿（唯一真源）+ Python 脚本（出图出报）+ 零依赖网页端（交互查看）**。

Excel 是真源。审计员日常就在 Excel 里维护风险登记册，整个模型用纯公式实现（MINIFS/MAXIFS，无需宏），打分完计算列自动出结果，参数在配置页改一个数，全簿自动重算。

Python 出报告。一次命令，输出热力图、领域分布、两期趋势哑铃图、等级迁徙矩阵、PDF 高管简报。还有个隐藏彩蛋：权重敏感性分析，把每个维度权重 ±20% 扰动重算排名，输出 TOP8 排名矩阵，这是回应"权重凭什么这么定"的答辩材料。

网页端零依赖。一个 HTML 文件，双击即用，离线可用，数据存在浏览器本地。汇报演示、打印存 PDF 全在浏览器里完成。优先级清单按剩余风险降序排好，附建议审计频次，直接当年度计划底稿。

三端共用同一套评分模型、同一份数据，数值完全一致。为了守住这条底线，写了 24 项评分模型单元测试，每次出报告末尾还会打印 TOP8 交叉验证表，Excel 公式的结果、Python 算的结果、网页算的结果，三者必须对得上。对不上就是 bug，对得上模型才可信。

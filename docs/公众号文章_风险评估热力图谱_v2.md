# 按风险大小排年度审计计划：一套打分可追溯的风险评估工具

> 从打分到排出年度审计计划的完整方法，配一个贯穿全篇的案例
> （配图源文件在 `output/` 目录，均为工具以内置示例数据生成的示意效果。）

---

审计部每年有一道必答题：年度审计计划，先审谁？

答案谁都认，按风险大小排。难的是风险大小怎么算得让人服。

我们做的这套风险评估工具，就是把这件事做成能算、能查、能答辩的活：八个影响维度加权打分，每个分值锚定权威标准，控制成效按短板折减，算完自动按剩余风险排序，直接产出年度审计计划的优先级底稿。

它的价值落在这三点：

**打分有依据。** 影响由八个维度加权合成，每个分值都能追溯到法规或国际标准，登记册里每条风险必须写打分依据，任何一档分都能被追问。

**排序有逻辑。** 年度计划按剩余风险排，控制化解掉的部分不占审计资源；致命维度有一票否决兜底，不会被"还好"稀释成低分。

**落地零门槛。** Excel 维护打分，Python 出图出报，网页端双击即用，三端同分。

下面用一个虚构的制造集团案例，把从打分到排出年度计划的完整链路走一遍。

## 一. 先造一家企业，三条风险

先虚构一家企业：某装备制造集团，年营收 30 亿，业务覆盖采购、生产、销售、工程、资金、安全环保全链条。风险登记册上 24 条风险，覆盖 4 大类 12 个领域。

今天用主价值链上最典型的三条，走完从打分到排出年度计划的完整链路：

**风险 A（采购）：供应商准入与围标串标。** 准入把关不严，关联供应商围标串标。近两年招标投诉 2 起，1 家关联供应商未申报。

**风险 B（生产）：生产安全事故隐患。** 高危作业管理不到位，年内发生 1 起未遂事故。

**风险 C（销售）：大客户依赖与应收账款回收。** 前五大客户占营收 55%，其中两家账期持续拉长，约 1.2 亿元应收账款存在回收风险。

## 二. 打分怎么打：影响不是一个数

传统做法是把"影响"打成 1 个分：大、中、小或 1-5。但影响分直接决定风险排第几，一个数说不清。一次围标串标，可能同时意味着采购价虚高（经济损失）、被监管处罚（合规法律）、供应商投诉发酵（声誉舆情），它本身就是舞弊风险（经办人舞弊）。只打一个"影响分"，等于让每个审计员在脑子里偷偷做加权，而且权重各不相同，排出来的序自然五花八门。

所以把"影响"拆成**八个维度**：

> **经济损失 / 合规法律 / 运营中断 / 声誉舆情 / 舞弊风险 / 战略影响 / 数据安全 / 健康安全**

每条风险按维度打 1-5 分，加权合成综合影响。这套加权有三个关键设计，直接关系排序靠不靠谱：

**维度独立性。** 各维度只评估自己的专属后果，经济损失维度不重复计入舞弊损失，声誉维度不重复计入合规处罚的舆情。不独立就重复计分，分数虚高，排序失真。

**维度可留空。** 不适用该维度的风险留空即可，留空维度不参与加权，权重在已打分维度上重新归一化。硬给不适用的维度打分，反而会把排序带偏。

**分领域权重矩阵。** 不同领域的风险，八个维度的"含金量"不一样：资金活动领域经济损失权重 32%，信息系统领域运营中断权重 28%，安全环保领域健康安全 20%、合规法律 22%，采购与外包领域舞弊权重 20%。12 个领域 × 8 个维度，每个领域一行权重矩阵。同一个"4 分"，落在资金活动里和落在信息系统里，贡献完全不同，排序才有区分度。

综合影响按下面的公式合成：

```
综合影响 I = MAX( Σ(wᵢ×维度ᵢ) / Σ(已评分维度的wᵢ) , 0.75 × 最高维度分 )
```

公式里 MAX 的第二项是一票否决下限，第三部分单独讲。

## 三. 打分怎么打：4 分到底是多少钱

八维拆完了，新的问题来了：**"经济损失 4 分"到底是多少钱？**

这个问题答不上来，排序就站不住。这是整个项目最花功夫的部分：给每一个维度的每一个分值找到权威刻度。

拿"经济损失"举例，1-5 档直接锚定国资委《中央企业违规经营投资责任追究实施办法》的资产损失分级：

| 分值 | 锚点 | 依据 |
|---|---|---|
| 1 | < 100 万元，企业内部可消化 | 国资委办法（一般以下） |
| 2 | 100~500 万元，构成"一般资产损失" | 国资委办法 |
| 3 | 500~5000 万元，"较大资产损失" | 国资委办法；国务院令第 493 号 |
| 4 | 5000 万~1 亿元，"重大资产损失" | 国资委办法 |
| 5 | ≥ 1 亿元，危及企业生存 | 国务院令第 493 号 |

其他维度同理："合规法律"锚定《个人信息保护法》第 66 条、《数据安全法》第 45 条的罚款区间，100 万以下一档、100~1000 万一档、1000 万~5000 万或营业额 5% 顶格一档，GDPR 的 2000 万欧元/全球营业额 4% 作国际对照；"舞弊风险"锚定 ACFE《Occupational Fraud 2024》损失基准，中位 14.5 万美元一档、75 分位 75 万一档、组织年均流失 5% 营收一档；"运营中断""健康安全"参照国务院令第 493 号的事故等级和 ISO 22301 的 RTO 分级；"战略影响"对齐 COSO ERM 2017 和《中央企业全面风险管理指引》。

全表 8 个维度 × 5 个分值，每个格子都有出处，直接内嵌在 Excel 工作簿里。打分从"个人经验"变成了"可复核的证据"：任何一档分数都可以被追问"依据是什么"，登记册里每一行还有一个"打分依据"字段，要求审计员写下引用的审计发现、监管动态或量化数据。

领导问"凭什么这条排前面"，答案就是"按国资委办法，5000 万以上属重大损失，这条风险的敞口测算在 1.2 亿"。

这套锚点体系，是整个项目最值得抄走的部分。哪怕不用工具，把这张锚点表拿去，你所在机构的评分标准立刻就有了骨架。

## 四. 分数怎么修正：两个兜底设计

固有分算出来了，还不能直接拿来排计划。两个兜底设计，都是排计划时最容易踩的坑。

**一票否决下限（0.75 × 最高维度分）。** 假设一条风险八维打分是 2 / 1 / 2 / 2 / 1 / 1 / 4 / 1，经济影响轻微，唯独数据安全打了 4 分（大量个人信息泄露）。按加权平均算只有约 1.83 分，低风险。但数据安全打到 4，按《个保法》第 66 条就是 1000 万~5000 万罚款档或营业额 5% 顶格的量级，被其他六个"轻微"维度稀释成 1.83 分，这说不通。如果允许稀释，这条风险会被排进年度计划的末尾，后果就是漏审。所以规则是：综合影响不得低于最高维度分 × 0.75，上面的例子直接被抬到 3.0 分。**任何单一维度的致命后果，都不允许被其他维度的"还好"稀释掉。** 等会儿风险 C 会实战触发一次。

**短板效应折减。** 固有风险算出来，只是风险的原貌。年度计划按剩余风险排：控制措施化解掉的部分，不该继续占用审计资源。每条风险挂 1~N 条控制点，每条打 1-5 的有效性分，剩余风险按"最弱的关键控制"折减，这就是木桶原理。比如风险 A 挂了三道控制：电子招投标平台留痕（4 分）、供应商关联关系申报承诺（3 分）、评标专家随机抽取（4 分）。其中招投标平台是关键控制，它失效，其他两道都只是摆设，所以折减只看这个 4 分：折减 55%。还有一条更狠的规则：**没有控制点的风险，不做任何折减，剩余 = 固有。** "没验证过的控制，不给信用。"你说你有控制，请先登记进来打个分；登记不上来，风险就按裸奔算，排序上一点便宜都占不到。

## 五. 案例闭环：三条风险，排出年度计划

理论讲完，回到开头那家制造集团。三条风险各算一遍，看它们在年度计划里排成什么样。

### 风险 A（采购）：供应商准入与围标串标

| 步骤 | 计算 | 结果 |
|---|---|---|
| 可能性 L | 行业围标高发 + 近两年投诉 2 起 | 4 分 |
| 八维影响 | 经济4 / 合规4 / 运营3 / 声誉3 / **舞弊5** / 战略3 / 数据1 | 按采购与外包领域权重加权 ≈ 3.75 |
| 综合影响 | MAX(3.75, 0.75×5) | 3.75 |
| **固有风险** | 4 × 3.75 | **15.00 → 高** |
| 最弱关键控制 | 电子招投标平台留痕 | 4 分 → 折减 55% |
| **剩余风险** | 15.00 × 0.45 | **6.75 → 中** |

舞弊维度打了 5 分，采购是舞弊高发地，领域权重里舞弊占 20%，加权平均正好压着一票否决线。固有 15 分，高；关键控制（招投标全流程留痕）4 分，折减后 6.75，落到"中"。

### 风险 B（生产）：生产安全事故隐患

| 步骤 | 计算 | 结果 |
|---|---|---|
| 可能性 L | 年内已发生 1 起未遂事故苗头 | 3 分 |
| 八维影响 | 经济4 / 合规5 / 运营5 / 声誉5 / 舞弊1 / 战略3 / 数据1 / **健康5** | 按安全环保领域权重加权 ≈ 4.70 |
| 综合影响 | MAX(4.70, 0.75×5) | 4.70 |
| **固有风险** | 3 × 4.70 | **14.10 → 高** |
| 最弱关键控制 | 高危作业许可制度 | 4 分 → 折减 55% |
| **剩余风险** | 14.10 × 0.45 | **6.35 → 中** |

安全环保领域的权重画像在起作用：健康安全 20%、合规法律与运营中断各 22%，生产事故的"综合影响"天然就高，加权平均 4.70 已经超过一票否决线。健康安全打 5 分，按 493 号令是"特别重大事故"（≥30 人死亡）的量级锚点，打分的人必须正视这个刻度。

### 风险 C（销售）：大客户依赖与应收账款回收

| 步骤 | 计算 | 结果 |
|---|---|---|
| 可能性 L | 两家大客户账期持续恶化 | 4 分 |
| 八维影响 | **经济5** / 合规2 / 运营3 / 声誉3 / 舞弊2 / 战略4 / 数据1 | 按资金活动领域权重加权 ≈ 3.35 |
| 综合影响 | MAX(3.35, **0.75×5**) | **3.75** |
| **固有风险** | 4 × 3.75 | **15.00 → 高** |
| 最弱关键控制 | 信用额度审批 | 3 分 → 折减 40% |
| **剩余风险** | 15.00 × 0.60 | **9.00 → 中** |

风险 C 是一票否决的实战现场：加权平均只有 3.35，但因为经济损失打了 5 分，1.2 亿应收敞口按国资委办法已是"重大资产损失"量级，综合影响被强制抬到 3.75。

三张表算完，年度计划落位表就出来了：

| 风险 | 固有 | 剩余 | 等级 | 年度计划落位 |
|---|---|---|---|---|
| C 销售应收 | 15.00 | 9.00 | 中 | 第 1 顺位，两年一轮，离"高"线只差 3 分 |
| A 采购围标 | 15.00 | 6.75 | 中 | 第 2 顺位，两年一轮，舞弊土壤仍在 |
| B 生产安全 | 14.10 | 6.35 | 中 | 第 3 顺位，两年一轮，防线够用但不容松动 |

注意固有排序和剩余排序不一样：固有风险 A 和 C 并列第一，折减之后 C 排第一、A 次之、B 最后。差别来自控制措施化解的敞口。年度计划按剩余风险排，三条都在"中"，两年一轮，其中 C 最该盯紧，信用审批得从 3 分往 4 分修。

## 六. 工具怎么落地：三件套

模型再漂亮，落不了地就是 PPT。这个项目是"三件套"：**Excel 工作簿（唯一真源）+ Python 脚本（出图出报）+ 零依赖网页端（交互查看）**。

Excel 是真源。审计员日常就在 Excel 里维护风险登记册，整个模型用纯公式实现（MINIFS/MAXIFS，无需宏），打分完计算列自动出结果，参数在配置页改一个数，全簿自动重算。

Python 出报告。一次命令，输出热力图、领域分布、两期趋势哑铃图、等级迁徙矩阵、PDF 高管简报。还有个隐藏彩蛋：权重敏感性分析，把每个维度权重 ±20% 扰动重算排名，输出 TOP8 排名矩阵，这是回应"权重凭什么这么定"的答辩材料。

网页端零依赖。一个 HTML 文件，双击即用，离线可用，数据存在浏览器本地。汇报演示、打印存 PDF 全在浏览器里完成。优先级清单按剩余风险降序排好，附建议审计频次，直接当年度计划底稿。

三端共用同一套评分模型、同一份数据，数值完全一致。为了守住这条底线，写了 24 项评分模型单元测试，每次出报告末尾还会打印 TOP8 交叉验证表，Excel 公式的结果、Python 算的结果和网页算的结果，三者必须对得上。对不上就是 bug，对得上模型才可信。

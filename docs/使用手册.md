## 1. 项目是什么

一套**通用内审风险评估工具**，围绕"风险热力图谱"提供三种使用形态，共用同一评分模型、同一份数据，三端数值完全一致：

| 形态 | 载体 | 适合场景 |
|---|---|---|
| **Excel 工作簿** | `audit_risk_register.xlsx` | 日常维护数据（唯一真源）、审计人员手工打分 |
| **Python 脚本** | `tools/` 目录 | 批量出图、生成 PDF 高管简报、集成到自动化流程 |
| **网页端** | `web/risk_heatmap.html` | 汇报演示、交互式探查、临时编辑、打印存 PDF |

核心能力：

- **多因素加权评分**：可能性 + 五维影响（经济损失/合规法律/运营中断/声誉舆情/舞弊风险）
- **短板效应控制折减**：每条风险挂多条控制点，按"最弱控制点"折算剩余风险
- **固有 / 剩余双热力图**：直观展示控制措施带来的风险改善
- **多期趋势对比**：两期剩余风险哑铃图，红=恶化、绿=改善
- **年度审计优先级**：按剩余风险自动排序 + 审计频次建议

## 3. 评分模型详解

### 3.1 计算公式

```
综合影响 I = MAX( 五维加权分 , 一票否决系数 × 最高维度分 )
固有风险   = 发生可能性 L × I
控制分     = MIN(关键控制点得分)                     ← 短板效应
剩余风险   = 固有风险 × (1 − 折减系数[控制分])
控制挽回率 = (固有风险 − 剩余风险) / 固有风险
```

- 五维加权分的权重**按风险所属领域自动取用**分领域权重矩阵（见 4.2），
  未在矩阵中列出的领域自动使用"全领域默认"行；
- **一票否决下限**（默认 0.75，可调）：任一维度打到 5 分，综合影响不低于 3.75；
  打到 4 分不低于 3.0——合规/舞弊类"一票否决型"后果不会被其他低分维度稀释；
- 综合影响 I ∈ [1, 5]，固有风险 ∈ [1, 25]，剩余风险 ∈ [0, 25]；
- **无控制点的风险不做任何折减**（剩余 = 固有）——未验证的控制不给信用；
- 所有中间值保留两位小数。

### 3.2 打分锚点（权威标准版）

> **维度独立性原则**：各维度只评估其**专属后果**——经济损失维度不重复计入
> 舞弊造成的损失，声誉维度不重复计入合规处罚带来的舆情。避免维度间重复计分，
> 这是五维加权结果可信的前提。
>
> 金额锚点以国资委资产损失分级为基准刻度，适合央企/国企；非国有企业可按
> 营收规模等比例缩放（建议保持相邻档位 5~10 倍跨度），缩放后须全所统一。

**发生可能性 L（1-5）**

| 分值 | 锚点 | 参考依据 |
|---|---|---|
| 1 | 同行业 5 年内无案例，控制健全且经测试 | COSO ERM 2017 风险偏好校准 |
| 2 | 同行业偶发，本企业 3~5 年内无案例 | — |
| 3 | 本企业 1~2 年内发生过苗头或一般性问题 | 内审发现/监管检查通报 |
| 4 | 本企业年内已发生，或同行业高发 | ACFE：组织年均约 5% 收入流失于舞弊，提示频发常态 |
| 5 | 已多次发生或正在发生，相关控制基本失效 | — |

**经济损失（1-5）** —— 锚：国资委《中央企业违规经营投资责任追究实施办法》资产损失分级（2026-01-01 施行）；国务院令第 493 号直接经济损失等级

| 分值 | 锚点 | 权威依据 |
|---|---|---|
| 1 | <100 万元：未达"一般资产损失"标准，企业内部可消化 | 国资委办法（一般以下） |
| 2 | 100~500 万元：构成"一般资产损失" | 国资委办法：<500 万为一般 |
| 3 | 500~5000 万元：构成"较大资产损失"；493 号令"较大事故"直接损失（1000~5000 万）落于本档 | 国资委办法；国务院令第 493 号 |
| 4 | 5000 万~1 亿元：构成"重大资产损失"；493 号令"重大事故"量级 | 国资委办法：≥5000 万为重大；493 号令 |
| 5 | ≥1 亿元：493 号令"特别重大事故"直接损失量级，危及企业生存 | 493 号令第三条 |

**合规法律（1-5）** —— 锚：《个人信息保护法》第 66 条、《数据安全法》第 45 条、《网络数据安全管理条例》、GDPR 第 83 条、国资委"不良后果"三档

| 分值 | 锚点 | 权威依据 |
|---|---|---|
| 1 | 内部制度瑕疵，责令整改即可，无外部后果 | — |
| 2 | 监管关注/责令限期整改；罚款 <100 万元 | 个保法第 66 条第一款（≤100 万） |
| 3 | 一般行政处罚，罚款 100~1000 万元；责任人被处分 | 数安法第 45 条（≤1000 万）；网数条例第 56 条 |
| 4 | 情节严重：罚款 1000~5000 万元或上年度营业额 5%（个保法顶格）；GDPR 顶格 2000 万欧/全球营业额 4% 同档 | 个保法第 66 条第二款；GDPR Art.83 |
| 5 | 刑事责任移送、责令停业/吊销执照；国资委"重大不良后果"（影响社会与国家层面） | 国资委办法不良后果分级；刑法/监察法管辖 |

**运营中断（1-5）** —— 锚：国务院令第 493 号事故等级 + ISO 22301 业务连续性 RTO 分级

| 分值 | 锚点 | 权威依据 |
|---|---|---|
| 1 | 局部岗位受阻，当日恢复（RTO<8h），无人员伤害 | ISO 22301 恢复目标分级 |
| 2 | 单部门中断，RTO 1~3 天；轻微伤害事件 | ISO 22301 |
| 3 | 跨部门/跨区域中断，RTO 3~30 天；或 493 号令"一般事故"（<3 人死亡，直接损失<1000 万） | 493 号令第三条 |
| 4 | 核心业务瘫痪 1~6 个月；或"较大/重大事故"量级（3~30 人死亡，损失 1000 万~1 亿） | 493 号令第三条 |
| 5 | 集团级核心业务瘫痪超 6 个月；或"特别重大事故"（≥30 人死亡或≥1 亿元损失） | 493 号令第三条 |

**声誉舆情（1-5）** —— 锚：国资委"不良后果"三档（影响层面：涉事企业→行业/央企整体→社会和国家）× 传播层级

| 分值 | 锚点 | 权威依据 |
|---|---|---|
| 1 | 无外部感知，仅内部知晓 | — |
| 2 | 个别投诉、本地媒体负面报道，影响限于涉事企业 | 国资委：一般不良后果 |
| 3 | 行业内流传、省级媒体或行业监管通报 | 国资委：较大不良后果 |
| 4 | 全国性媒体报道、上级机关通报批评，资本市场负面反应（评级下调/股价波动） | 国资委：较大~重大不良后果 |
| 5 | 国家级媒体或监管部门点名、形成社会舆论事件、引发行业整顿 | 国资委：重大不良后果（社会和国家层面） |

**舞弊风险（1-5）** —— 锚：ACFE《Occupational Fraud 2024》损失基准（按 ≈7.2 汇率折算）+ 监察机关职务犯罪管辖 + 国资委追责分级

| 分值 | 锚点 | 权威依据 |
|---|---|---|
| 1 | 无舞弊诱因，职责分离健全且经穿行测试，无历史案例 | COSO 控制环境；ISO 37001 |
| 2 | 存在一般诱因但控制可见；潜在损失 <100 万元（ACFE 中位数以下） | ACFE 2024：中位损失 $14.5 万 |
| 3 | 诱因集中（权限集中/监督薄弱）；潜在损失 100~500 万元（中位~75 分位区间） | ACFE 2024：75 分位 $75 万 |
| 4 | 诱因高危或有历史案例；潜在损失 500~5000 万元；涉嫌职务违法（监察机关管辖） | 国资委较大~重大资产损失档 |
| 5 | 系统性舞弊土壤（管理层凌驾/集体舞弊）；潜在损失 ≥5000 万元或 ≥年营收 5%（ACFE 年流失率基准） | ACFE：组织年均 5% 收入流失于舞弊 |

**锚点权威来源汇总**

| # | 来源 | 用途 |
|---|---|---|
| 1 | 国务院国资委《中央企业违规经营投资责任追究实施办法》（2025 年修订，2026-01-01 施行，替代原 37 号令） | 经济损失三档（500 万/5000 万）、不良后果三档、舞弊追责 |

| 4 | GDPR 第 83 条（2000 万欧元或全球营业额 4%） | 合规档位的国际对照 |

### 3.3 控制有效性评分与折减

每条风险可挂 **1~N 条控制点**（如"网银双人复核""权限季度复核"），每条按 1-5 打有效性分，
并标记**是否关键控制**：

| 最弱控制分 | 折减系数 | 含义 |
|---|---|---|
| 1 | 0% | 控制形同虚设 |
| 2 | 15% | 控制薄弱 |
| 3 | 40% | 控制基本存在但有明显缺陷 |
| 4 | 55% | 控制较好，偶有例外 |
| 5 | 70% | 控制健全且有效执行 |

**关键控制与短板效应**：剩余风险按该风险**关键控制点的最低分**取折减系数；
若未标记任何关键控制，退回按全部控制点最低分。只评估"最弱一环"符合内审
木桶原理——一条关键控制失效，整项风险即不能视为受控。

**控制挽回率** = (固有 − 剩余) / 固有，衡量控制环境化解风险的比例。
按领域汇总后（汇总页领域表 / 报告脚本领域排名），可直接用于展示内审与
控制体系的价值："财务收支领域控制挽回率 55%，即控制措施化解了过半的固有风险敞口。"

### 3.4 风险领域体系（对齐内部审计准则框架）

领域分类参照两份权威框架：**《企业内部控制应用指引》（18 项）** 提供业务循环颗粒度，
**《中央企业全面风险管理指引》** 提供风险大类（战略/市场/财务/运营/法律）。
归并为 **4 大类 × 12 领域**：

| 大类 | 领域 | 对应内控应用指引 |
|---|---|---|
| 战略与治理 | 战略与投资 | 发展战略 |
| 战略与治理 | 治理与决策 | 组织架构、"三重一大"决策制度 |
| 财务 | 资金活动 | 资金活动（筹资/投资/营运） |
| 财务 | 财务报告与税务 | 财务报告、全面预算 |
| 财务 | 资产管理 | 资产管理（存货/固定资产/无形资产） |
| 运营 | 采购与外包 | 采购业务、业务外包 |
| 运营 | 合同管理 | 合同管理 |
| 运营 | 工程项目 | 工程项目 |
| 运营 | 人力资源 | 人力资源 |
| 运营 | 信息系统 | 信息系统 |
| 合规与安全 | 合规与法律 | 法律风险、合规管理 |
| 合规与安全 | 安全环保 | 安全生产、环境保护、社会责任 |

> 指引中的"市场风险"在审计语境下并入运营类各领域（价格波动体现在具体业务影响打分中）。
> 每个领域在参数配置页有专属权重行（见 4.2），体现领域风险画像差异。

## 4. Excel 真源工作簿操作指南

### 4.2 参数配置页

| 参数 | 位置 | 默认值 | 说明 |
|---|---|---|---|

### 4.3 风险登记册（日常主战场）

数据区从第 4 行开始，已预留至 200 行。

| 列 | 字段 | 录入/公式 | 说明 |
|---|---|---|---|
| A | 风险编号 | 录入 | 建议 R001、R002… 全簿唯一 |
| B | 风险名称 | 录入 | 简短名词短语 |
| C | 所属领域 | 录入（下拉） | 财务收支/采购与合同/工程建设/信息系统/人力资源管理/资产管理 |
| D | 风险描述 | 录入 | 一句话描述风险情形 |
| E | 责任部门 | 录入 | |
| F | 评估期间 | 录入（下拉） | 默认 2025H2 / 2026H1 |
| G | 发生可能性 | 录入（1-5） | 下拉限选，超范围拒绝 |
| H~L | 五维影响 | 录入（1-5） | 经济损失/合规法律/运营中断/声誉舆情/舞弊风险 |
| M~U | 计算列 | 公式 | 综合影响、固有、最弱控制分、折减、剩余、等级、辅助档位、建议频次 |
| V | 控制挽回率 | 公式 | (固有−剩余)/固有，百分比显示 |
| W | 打分依据 | 录入 | 证据导向：引用审计发现、监管动态、量化数据，支撑六项打分的复核 |

**日常操作**：新增一行 → 填 A~L → 计算列自动出结果。删除风险时建议整行删除
（同时到「控制措施表」清理其控制点）。

### 4.4 控制措施表

数据区从第 4 行开始，已预留至 150 行。

| 列 | 字段 | 说明 |
|---|---|---|
| A | 控制编号 | C001、C002… |
| B | 关联风险编号 | 下拉引用登记册已有编号 |
| C | 评估期间 | 必须与所关联风险的期间一致 |
| D | 控制点描述 | 具体控制活动名称 |
| E | 有效性评分 | 1-5，下拉限选 |
| F | 关键控制 | 是/否 下拉；剩余风险按关键控制的最低分折减 |

> 一条风险挂几条控制点不限；**剩余风险只看关键控制中最弱的一条**
> （未标记关键控制时退回全部控制点取最低）。

### 4.5 热力图页

- 右上角 **C3 单元格**为期间筛选器（2025H2 / 2026H1 / 全部），两张矩阵联动；
- **固有矩阵**：格内数字 = 落入该（可能性 × 影响档）格的风险数量，底色按格子固有分值；
- **剩余矩阵**：格内数字 = 该位置风险的剩余分**均值**，底色随阈值联动；
- 单条风险的精确剩余分请看「汇总与优先级」页或登记册 Q 列。

### 4.6 汇总与优先级页

- 期间与热力图页联动（B2 自动镜像）；
- **领域汇总表**：各领域的风险数、平均/最高剩余分、极高/高风险数、**平均控制挽回率**；
- **优先级清单**：全部风险按剩余风险降序排名（含同分按编号次序的稳定排序），
  含固有、最弱控制、剩余、等级色块、建议频次，可用 Excel 筛选按领域/部门过滤，
  直接作为年度审计计划编制底稿。

### 4.7 环境要求

- **Excel 2019 / Microsoft 365 及以上**（公式使用 MINIFS、MAXIFS）；
- 纯公式实现，**无需启用宏**；WPS 表格对 MINIFS 支持不全，不建议使用。

## 5. Python 脚本操作指南

### 5.1 环境准备

- Python 3.10+（开发验证于 3.13）
- 依赖仅两个：`pip install matplotlib openpyxl`
- 中文图表字体使用微软雅黑（Windows 自带）

### 5.2 命令一览

| 命令 | 作用 | 常用参数 |
|---|---|---|
| `python tools\build_excel.py` | 重建含示例数据的工作簿（**会覆盖**现有 xlsx） | 无 |
| `python tools\export_from_excel.py` | xlsx → CSV 对 + config.json | `--xlsx` 指定其他工作簿路径 |
| `python tools\generate_report.py` | CSV → PNG 图集 + PDF 简报 | 见下 |
| `python tools\sample_data.py` | 重置示例数据（CSV + 网页内置数据） | 无 |
| `python -m unittest discover -s tests` | 运行 21 项评分模型一致性测试 | 无 |

`generate_report.py` 参数：

| 参数 | 默认 | 说明 |
|---|---|---|
| `--period` | 字典序最大的期间 | 基准评估期间 |

示例：

```powershell

# 附加权重敏感性分析（汇报答辩用）
python tools\generate_report.py --sensitivity
```

### 5.3 输出物说明（output/ 目录）

| 文件 | 内容 | 汇报用法 |
|---|---|---|
| `{期间}_inherent_heatmap.png` | 固有风险气泡热力图 | 展示"风险原貌" |
| `{期间}_residual_heatmap.png` | 剩余风险气泡热力图 | 展示"控制成效" |

## 6. 网页端操作指南

打开 `web/risk_heatmap.html` 即用。**零依赖、离线可用**，数据保存在浏览器 localStorage。

### 6.1 界面分区（自上而下）

1. **顶栏**：评估期间选择、对比期间选择、载入内置示例、打印/存 PDF；
2. **指标卡**：风险总数、平均剩余分、极高风险数、高风险数；
3. **双热力图**：左固有右剩余；气泡悬停显示摘要，**点击气泡（或优先级清单行）打开右侧详情栏**——完整档案含打分依据、六项打分、计算过程、控制点清单（关键标记）、两期对比；
4. **两期趋势对比**：哑铃图（TOP12 变化幅度）+ 全量变化表 + **等级迁徙矩阵**（对角线=持平，左下=改善，右上=恶化）；
5. **年度审计优先级清单**：排名、等级色块、挽回率、建议频次；

7. **评分参数**（不打印）：权重（实时合计校验）、阈值、折减映射、一票否决系数、**分领域权重矩阵**。

### 6.2 数据导入 / 导出

- **导入**：「数据维护」区依次选择 `risks.csv`、`controls.csv`、`config.json`（可选）。
  按文件内 `period` 列自动归入对应期间，可一次导入多期文件实现趋势对比；
- **导出**：优先级清单下方三个按钮，导出当前期间的 risks.csv / controls.csv / config.json
  （带 BOM，Excel 直接打开不乱码），可与 Excel 真源双向核对。

### 6.3 在线编辑

- **新增风险**：填编号（留空自动顺延 R00x）、名称、领域、部门、描述、六项打分 → 「保存风险」；
- **修改风险**：清单中点「编辑」，表单载入后修改再保存；
- **删除风险**：点「删除」，其控制点一并删除；
- **维护控制点**：右上选择所属风险 → 填描述、选有效性分、选是否**关键控制** → 「添加」；
  已有控制点可改分/改关键标记/删除。

所有改动即时重算并自动保存（刷新页面不丢失）。

### 6.4 调整评分参数

「评分参数」面板：五个权重输入框下方实时显示合计（绿色=合法，红色=≠1）；
阈值与折减系数修改后全页即时重算。与 Excel 参数配置页等效，两边改任一边注意同步。

打印视图自动隐藏编辑与导入区，保留指标卡、双热力图、趋势、优先级清单，横版效果最佳。

- 换电脑/换浏览器需重新导入 CSV；
- 「清空本机数据」恢复到内置示例状态，操作前请确认已导出。

## 7. 数据流转与一致性原则

```
            ┌──────────── 唯一真源 ────────────┐
            │      audit_risk_register.xlsx   │
            └───────┬──────────────┬──────────┘
        export_from_excel.py     （手工另存/对照）
            ┌───────┴────────┐     ┌──────┴──────┐
            │ risks.csv      │     │ 网页端导入    │
            │ controls.csv   │ ──→ │ localStorage │
            │ config.json    │     └─────────────┘
            └───────┬────────┘
             generate_report.py
            ┌───────┴────────┐
            │ PNG ×4 + PDF   │
            └────────────────┘
```

**三条铁律**：

1. **Excel 是唯一真源**。网页 localStorage 只是草稿，定期以 Excel 导出为准；
2. **CSV 是唯一交换格式**。三端数值一致性由共享公式保证，`generate_report.py`
   末尾的 TOP8 表是验收依据；
3. **参数改动要三端同步**。权重/阈值/折减在 Excel「参数配置」或网页「评分参数」
   任一处修改后，记得导出/导入 config.json 对齐另一端。

## 8. 常见任务手册

### 8.1 新增一条风险

Excel：登记册第一个空行填 A~L 列 → 控制措施表为它挂控制点 → 完成。
网页端：「数据维护」表单填写后保存（别忘了补控制点，否则不折减）。

### 8.2 开始新一期评估（如 2026H2）

1. 「参数配置」页 I 列期间清单的空行填入 `2026H2`（登记册、控制表、热力图下拉自动同步）；
2. 复制上期风险行，改 F 列为新期间，按本期情况更新 G~L 打分；
3. 控制措施表同理复制上期控制点并改期间、更新 E 列评分；
4. `python tools\export_from_excel.py` → 自动生成 `data/export/2026H2/`；
5. `python tools\generate_report.py` 自动识别最新期间并默认与上一期对比；
6. 网页端导入新 CSV 即可查看三期数据（趋势对比任选两期）。

### 8.3 调整权重 / 阈值 / 折减

Excel 参数配置页直接改 → 全簿自动重算 → 重新导出使 config.json 同步。
网页端在「评分参数」面板改。**注意**：权重合计≠1 时导出脚本会拒绝执行并提示。

### 8.4 换行业 / 换领域适配

1. `tools/common.py` 修改 `DOMAINS` 领域清单与 `DOMAIN_CATEGORY` 大类映射；
2. Excel 登记册 C 列数据验证同步修改来源列表；参数配置页权重矩阵按新领域增删行
   （注意同步修改登记册 M 列公式中的矩阵引用范围 $A$26:$F$38）；
3. 网页端修改脚本顶部 `DOMAINS` 常量与 `DOMAIN_CATEGORY`；
4. 替换 `tools/sample_data.py` 中的示例风险后运行 `python tools\sample_data.py`。
   评分模型本身无需任何改动。

### 8.5 增减影响维度（进阶）

涉及三处联动：`tools/common.py` 的 `DIMS`/`DIM_LABELS` 与默认权重；
Excel 参数配置权重区、登记册 M 列公式；网页端 `DIMS` 常量与表单字段。
建议由 IT 支持人员操作，改完跑一遍第 5.4 节交叉验证。

### 8.6 只想出某一条风险的说明材料

网页端导入数据后，在优先级清单用浏览器页内查找（Ctrl+F）定位该风险，
配合热力图悬停明细截屏即可。

## 9. FAQ 与故障排查

**Q1：打开 xlsx 提示公式错误 / 计算列全空？**
Excel 版本低于 2019（缺 MINIFS/MAXIFS）。请升级 Office 或使用网页端。

**Q2：导出脚本报"权重之和必须为 1"？**
参数配置页 B8 合计格变红。把五个权重改到合计=1（如 30%+25%+15%+15%+15%）再导出。

**Q3：某条风险的剩余分等于固有分？**
该风险在当前期间没有控制点，或控制措施表的期间与风险的期间不一致（短板查找按"编号+期间"匹配）。

**Q4：网页打开后图表空白？**
① 点「载入内置示例」；② 若导入过数据，检查 CSV 是否选对（risks 与 controls 分开两个输入框）；
③ 极端情况下点「清空本机数据」重置。

**Q5：CSV 用 Excel 打开中文乱码？**
本项目导出的 CSV 已带 BOM 不会乱码；若你自己另存的文件乱码，另存为时选"CSV UTF-8"。

**Q6：图表中文显示为方框？**
非 Windows 系统需安装微软雅黑，或修改 `tools/generate_report.py` 顶部
`font.sans-serif` 为本机可用中文字体（如思源黑体）。

**Q7：热力图上多个气泡挤在一格？**
同格风险自动错开摆放；精确分值请看优先级清单或登记册，鼠标悬停网页气泡可看明细。

**Q8：想撤销网页端的修改？**
未导出前可点「清空本机数据」回示例状态；正式数据请始终以 Excel 为准重新导入。

**Q9：build_excel.py 会覆盖我填的数据吗？**
会。它用于首次生成或重置演示。日常维护请直接在现有 xlsx 上操作，不要重跑该脚本。

**Q10：能多人同时维护吗？**
当前为单机文件方案。多人协作建议：Excel 放共享盘由专人维护，其余人只读消费
CSV/报告；后续可基于 `data/export` 的 CSV 接口接入业务系统（预留了 Risk as Code 升级路径）。

**Q11：关键控制标记有什么讲究？**
每条风险建议只把"一旦失效该风险即不受控"的核心控制标为关键（通常 1~2 条）。
标记越多，短板效应覆盖面越大，剩余风险越高——这是有意的保守取向。
全部不标记时退回"全部控制点取最低"，相当于把所有控制都当关键。

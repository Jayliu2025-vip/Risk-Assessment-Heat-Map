# v1.2.1 · Windows 桌面安装版

本版简化了大模型配置，并缩小桌面安装包和部分运行时内存占用。风险评分模型与工作簿格式仍为 1.2。

## 下载与安装

下载 `RiskAssessmentHeatMap-Setup-v1.2.1-windows-x64.exe`，按安装向导操作。适用于 Windows 10/11 x64；需要 Microsoft Edge WebView2 运行时，缺少指定 VC++ 运行库时安装程序会调用微软前置组件。

已有桌面版可覆盖升级。模型配置、Windows 凭据管理器中的密钥和用户报告目录会保留；卸载删除程序文件及快捷方式，保留上述用户数据。

可用 Windows PowerShell 的 `Get-FileHash -Algorithm SHA256` 与附件 `SHA256SUMS.txt` 核对安装包。

## 主要变化

- 大模型配置改为“选择服务商 → 粘贴密钥 → 保存并验证”，内置 DeepSeek、百炼、GLM、Kimi 预设及官方密钥指南。
- 编辑已有配置时自动回填字段，密钥留空保留；更换服务地址需要重新提供相应密钥。
- 支持常见版本化兼容地址和末尾斜杠；区分鉴权失败、限流、超时等错误。
- GLM 与 Kimi 官方接口使用服务商默认采样参数。
- 去除桌面流程不用的绘图组件与视频解码库；升级会清理旧版遗留组件。
- 限制默认 BLAS 线程数量，保留管理员显式指定的线程设置。
- 修正开始菜单快捷方式位置，安装登记版本更新为 1.2.1。

## 体积与内存

安装包约 103 MiB，程序目录约 247 MiB，分别比上一候选基线减少约 14% 和 16%。本机合成识别主进程的专用提交内存峰值由约 755 MiB 降至 364 MiB；物理内存峰值仍约 433 MiB。测试不包含 WebView2 进程树，不代表大型真实报告的内存峰值。

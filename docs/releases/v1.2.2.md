# v1.2.2 · 一套模型配置，自动处理图片能力

本版移除大模型“高级设置”和手动图片开关。选择服务商、填写密钥并保存即可，文字与图片使用同一套模型配置。风险评分模型与工作簿格式仍为 1.2。

## 主要变化

- 服务地址直接显示并由预设自动填写，配置名称自动生成。
- 保存时先验证文字连接，再用一张小测试图片检查当前模型的图片读取能力。
- 支持图片时，自动处理文字识别失败的报告页。
- 图片调用不可用或能力暂未确认时，只显示简短提示，继续使用文字识别。
- 保留 DeepSeek、百炼、GLM、Kimi 预设及原有密钥保留规则。

图片检查使用合成内容，不会读取用户报告；验证会请求所选服务，可能产生少量 API 费用。图片检查通过不代表复杂扫描页一定能准确识别，审计发现仍需人工复核。

## 安装与升级

下载 `RiskAssessmentHeatMap-Setup-v1.2.2-windows-x64.exe`。适用于 Windows 10/11 x64，使用系统 WebView2 运行时；缺少指定 VC++ 运行库时，安装程序会调用微软前置组件。

支持从 1.2.1 覆盖升级。模型配置、凭据和报告信息保留；重新打开软件后，点击“保存并验证”更新图片能力。卸载删除程序文件、快捷方式和卸载登记，保留用户数据与凭据。
